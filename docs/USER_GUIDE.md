# EarthScope v2.0 — User Guide

---

## 1. 플랫폼 소개

EarthScope는 **Google Earth Engine(GEE)** 기반 위성 영상 분석 웹 플랫폼입니다.  
브라우저에서 위성 이미지를 검색하고, 다양한 분광 분석 및 딥러닝 기반 탐지를 수행할 수 있습니다.

### 1.1 지원 위성

| 위성 | 유형 | 해상도 | 밴드 | 특징 |
|------|------|--------|------|------|
| **Sentinel-2** | 광학 (다중분광) | 10m / 20m | B2, B3, B4, B5, B6, B7, B8, B8A, B11, B12 | 구름량 필터링 지원, 식생/수체 분석에 최적 |
| **Sentinel-1** | SAR (레이더) | 10m | VV, VH | 날씨/구름 영향 없음, 지표 구조 분석 |

### 1.2 화면 구성

```
┌──────────────────────────────────────────────────────────────┐
│                     🛰️ EarthScope                             │
├────────────┬──────────────────────────────┬──────────────────┤
│            │                              │                  │
│  왼쪽 패널  │         지도 (Leaflet)        │   오른쪽 패널    │
│            │                              │                  │
│ · 위성 검색 │  · AOI 그리기                 │ · 분석 결과 목록  │
│ · 로컬 이미지│  · 결과 오버레이              │ · 스펙트럼       │

│            │                              │                  │

```

- **왼쪽 패널** — 위성 검색, 밴드 설정, 로컬 이미지 업로드, 레이어 관리
- **중앙 지도** — Leaflet 기반 인터랙티브 지도. AOI 설정, 분석 결과 시각화
- **오른쪽 패널** — 분석 결과 카드, 스펙트럼 인스펙터 (이미지 처리 후 자동 표시)

## 2. 위성 이미지 검색 및 처리

### 2.1 관심 영역(AOI) 설정

이미지를 검색하려면 먼저 관심 영역을 지정해야 합니다. 세 가지 방법을 지원합니다:

- **좌표 입력** — 상단 입력창에 `위도, 경도` 입력 후 "Go" 클릭 (예: `26.761, 103.794`)
- **지도에서 직접 그리기** — "Draw AOI" 버튼 클릭 → 지도 위에서 사각형 드래그
- **파일 업로드** — SHP(zip 압축) 또는 KML 파일을 드롭존에 드래그 앤 드롭

### 2.2 검색 조건 설정

| 항목 | 설명 | 기본값 |
|------|------|--------|
| Start Date / End Date | 검색할 날짜 범위 | — |
| Max Cloud Cover | 최대 허용 구름량 (0~100%) | 20% |
| Satellite | Sentinel-2 (광학) 또는 Sentinel-1 (SAR) 선택 | Sentinel-2 |

### 2.3 밴드 시각화 설정

검색 전에 어떤 밴드 조합으로 이미지를 볼 것인지 설정합니다.

**Sentinel-2의 경우:**
- 밴드 칩(B2, B3, B4 등)을 **R / G / B 슬롯에 드래그 앤 드롭**
- 기본값: R=B4(Red), G=B3(Green), B=B2(Blue) → 자연색(True Color)
- **Percentile Stretch** 슬라이더로 밝기/대비 조정
- 대표적인 밴드 조합 예시:
  - `B4, B3, B2` — 자연색 (True Color)
  - `B8, B4, B3` — 근적외선 합성 (NIR False Color, 식생이 빨갛게 보임)
  - `B12, B8, B4` — SWIR 합성 (수분/토양 강조)

**Sentinel-1의 경우:**
- VV, VH 밴드를 R/G/B 슬롯에 배치
- 기본값: R=VV, G=VH, B=VV

### 2.4 검색 실행

"Search Satellite Images" 클릭 → 조건에 맞는 이미지가 썸네일 목록으로 표시됩니다.
- 결과는 구름량 순으로 정렬
- 썸네일 클릭 시 지도에서 해당 이미지 미리보기
- 원하는 이미지를 선택하면 지도에 표시됨

### 2.5 이미지 분석 진행

이미지 선택 후 **"Analyze →"** 버튼을 클릭하면:
1. 서버가 GEE에서 해당 이미지의 전체 밴드를 다운로드
2. 구름 마스크 계산 (Sentinel-2)
3. 모델 예측 수행 (모델이 설치된 경우)
4. 완료 후 오른쪽 패널에 분석 결과 카드가 표시됨

> 처리 중에는 진행률 표시와 함께 로딩 오버레이가 나타납니다.

## 3. 분광 분석 (Spectral Analysis)

이미지 처리가 완료된 후 오른쪽 분석 패널에서 **"Spectral Analysis"** 를 통해 실행합니다.

### 3.1 분광 지수(Spectral Index)란?

위성 이미지의 특정 밴드 간 비율을 계산하여 식생, 수분, 수체 등의 특성을 수치화하는 방법입니다.
각 픽셀마다 하나의 값이 계산되며, 이 값을 컬러맵으로 시각화합니다.

### 3.2 지원하는 분광 지수

#### NDVI (Normalized Difference Vegetation Index) — 정규화 식생 지수

```
NDVI = (NIR - RED) / (NIR + RED)
     = (B8 - B4) / (B8 + B4)
```

- **용도**: 식생의 활력도 및 밀도 측정
- **값 범위**: -1 ~ 1
  - `0.6 ~ 1.0` → 건강한 식생 (짙은 녹색)
  - `0.2 ~ 0.6` → 중간 정도 식생
  - `0.0 ~ 0.2` → 나지(裸地) 또는 약한 식생
  - `-1.0 ~ 0.0` → 수체, 인공 구조물
- **활용**: 맹그로브 식생 분포 확인, 식생 건강도 평가

#### MVI (Mangrove Vegetation Index) — 맹그로브 식생 지수

```
MVI = (NIR - GREEN) / (SWIR1 - GREEN)
    = (B8 - B3) / (B11 - B3)
```

- **용도**: 맹그로브 숲을 다른 식생과 구분
- **특징**: 맹그로브의 수분 함량 특성을 반영하여 일반 식생과 차별화
- **활용**: 맹그로브 분포 매핑에 특화된 지수

#### NDMI (Normalized Difference Moisture Index) — 정규화 수분 지수

```
NDMI = (NIR - SWIR) / (NIR + SWIR)
     = (B8 - B11) / (B8 + B11)
```

- **용도**: 식생 내 수분 함량 측정
- **값 범위**: -1 ~ 1
  - 양수 값 → 수분이 풍부한 식생
  - 음수 값 → 건조한 토양/식생
- **활용**: 가뭄 모니터링, 습지대 식별

#### NDWI (Normalized Difference Water Index) — 정규화 수체 지수

```
NDWI = (GREEN - NIR) / (GREEN + NIR)
     = (B3 - B8) / (B3 + B8)
```

- **용도**: 수체(물) 영역 탐지
- **값 범위**: -1 ~ 1
  - 양수 값 → 수체 (호수, 강, 바다)
  - 음수 값 → 육지/식생
- **활용**: 해안선 추출, 수체 면적 측정

#### Custom Index — 사용자 정의 지수

원하는 밴드를 직접 선택하여 Normalized Difference 수식을 적용할 수 있습니다.

### 3.3 분광 분석 사용법

1. 분석 패널에서 원하는 **지수 선택** (NDVI, MVI, NDMI, NDWI, Custom)
2. 실행하면 계산 결과가 **컬러맵 오버레이**로 지도 위에 표시됨
3. 오른쪽 결과 카드에서:
   - **컬러바**: 값 범위 (최소 ~ 최대) 확인
   - **임계값 슬라이더**: 이중 슬라이더로 특정 범위만 필터링  
     (예: NDVI > 0.3 인 영역만 표시 → 식생 영역 추출)
   - **통계 정보**: 최소/최대/평균/표준편차
4. 여러 지수를 동시에 계산하여 레이어로 중첩 가능
5. 각 레이어별 표시/숨김 토글 가능

### 3.4 스펙트럼 인스펙터 (Spectral Inspector)

오른쪽 패널의 **"Spectral Inspector"** 탭에서 개별 픽셀이나 영역의 분광 프로파일을 직접 확인할 수 있습니다.

- **Point 모드** (📍): 지도에서 픽셀 클릭 → 해당 픽셀의 전체 밴드 값을 라인 그래프로 표시
- **Area 모드** (⬜): 사각형 영역 드래그 → 영역 내 평균 분광 프로파일 수집
- 최대 10개까지 서로 다른 색상으로 누적 수집 → 여러 지점의 분광 특성을 한 그래프에서 비교
- "Clear All"로 전체 초기화

> 예: 맹그로브 위의 픽셀과 물 위의 픽셀을 각각 클릭하여 분광 프로파일 차이를 비교

## 4. 타겟 탐지 (Target Detection)

사용자가 지정한 기준 픽셀(타겟)과 유사한 분광 특성을 가진 영역을 이미지 전체에서 탐지하는 기능입니다.

### 4.1 타겟 탐지란?

위성 이미지에서 "이 픽셀과 비슷한 곳을 전체 이미지에서 찾아줘"라는 개념입니다.  
사용자가 맹그로브, 특정 식생, 수체 등의 기준점을 클릭하면, 알고리즘이 해당 분광 특성을 기반으로 유사 영역을 점수화합니다.

### 4.2 사용법

1. 분석 결과 패널에서 **"Target Detection"** 클릭
2. **기준점 설정** (지도에서 클릭):
   - **좌클릭** — Positive 포인트 (녹색 마커): 찾고 싶은 대상 위 클릭
   - **우클릭** — Negative 포인트 (빨간 마커): 배경 또는 제외할 대상 클릭
   - 실행 취소(Undo) 및 전체 초기화(Clear) 가능
3. **알고리즘 선택** (드롭다운)
4. **밴드 선택** (선택사항, 기본값: 전체 밴드 사용)
5. **"Run Detection"** 클릭

### 4.3 탐지 알고리즘

| 알고리즘 | 풀네임 | 원리 | 적합한 경우 |
|----------|--------|------|------------|
| **SAM** | Spectral Angle Mapper | 타겟과 각 픽셀 간 분광 벡터의 각도를 측정. 각도가 작을수록 유사 | 밝기 변화에 강건한 탐지가 필요할 때 |
| **ACE** | Adaptive Cosine Estimator | 배경 통계를 반영한 정규화 매칭. 배경 잡음을 제거하고 타겟 신호를 강조 | 복잡한 배경에서 타겟을 구분해야 할 때 |
| **MF** | Matched Filter | 타겟의 분광 시그니처와 매칭되는 정도를 점수화 | 특정 물질의 존재 여부를 빠르게 판단할 때 |
| **CEM** | Constrained Energy Minimization | 타겟 신호의 에너지를 최대화하면서 배경 에너지를 최소화 | 미세한 타겟을 배경에서 분리해야 할 때 |
| **MLP_AMF** | MLP Adaptive Matched Filter | 신경망(MLP)으로 학습한 적응형 매칭 필터 | 비선형적 분광 패턴 탐지가 필요할 때 |
| **MLP_ACE** | MLP ACE variant | 신경망 기반 ACE 변형 | 학습 기반으로 더 정밀한 탐지가 필요할 때 |

### 4.4 결과 해석

- **탐지 점수 맵**: 각 픽셀에 0~1 범위의 점수가 부여됨 (1에 가까울수록 타겟과 유사)
- **컬러맵**: 점수를 색상으로 시각화
- **임계값 조절**: 슬라이더로 특정 점수 이상만 표시하여 이진 마스크 생성
- 여러 알고리즘의 결과를 동시에 레이어로 중첩하여 비교 가능

## 5. 세그멘테이션 (Segmentation)

### 5.1 맹그로브 세그멘테이션 (딥러닝)

Segformer 딥러닝 모델을 사용하여 이미지에서 맹그로브 영역을 자동으로 분류합니다.

> ⚠️ 모델 파일이 서버에 설치되어 있어야 동작합니다. 모델이 없어도 분광 분석, 타겟 탐지 등 다른 기능은 정상 사용 가능합니다.

**사용법:**

1. 분석 결과에서 **"Mangrove Segmentation"** 클릭
2. **TTA (Test-Time Augmentation)** 토글:
   - ON → 여러 각도로 예측 후 평균 → 정확도 향상, 처리 시간 증가
   - OFF → 단일 예측 → 빠른 처리
3. **"Run Segmentation"** 클릭
4. 결과: 확률 맵이 지도 위에 히트맵으로 표시 (0 = 비맹그로브, 1 = 맹그로브)
5. 임계값 슬라이더로 이진 마스크 생성 (예: 0.5 이상만 맹그로브로 분류)

**모델 상세:**
- 입력: Sentinel-2 전체 밴드 (13개)
- 출력: 픽셀별 맹그로브 확률 (0~1)
- Gaussian 가중치 패치 블렌딩으로 이음새 없는 결과 생성
- GPU(CUDA) 가속 지원, GPU가 없으면 CPU 폴백

### 5.2 SAM3 세그멘테이션 (인터랙티브 + 텍스트)

Segment Anything Model v3는 두 가지 모드를 제공합니다:

**Point 모드 (기존 SAM2 방식)**

1. 분석 결과에서 **"SAM3 Segmentation"** 클릭 → 상단 토글에서 **📍 Point** 선택
2. 지도에서 포인트 클릭:
   - **Positive** (녹색): 분할하고 싶은 객체 위 클릭
   - **Negative** (빨간색): 제외할 배경 영역 클릭
3. 포인트를 추가할 때마다 **실시간으로 마스크 미리보기** 업데이트
4. 만족하면 **"💾 Save"** 클릭 → 현재 마스크 저장 후 다음 객체 작업
5. 저장된 마스크 목록에서 개별 표시/숨김/삭제

**Text 모드 (Promptable Concept Segmentation)**

1. 상단 토글에서 **🅰 Text** 선택
2. 입력박스에 명사구(예: `mangrove`, `boat`, `building`) 입력 후 **🔍 Run**
3. AOI/이미지 안의 **모든 인스턴스**가 한 번에 인스턴스별 색상으로 표시됨
4. 우측 인스턴스 리스트에서:
   - 🔍 줌, 👁 표시 토글, 💾 개별 저장, ✕ 삭제
   - 행 클릭 → 해당 인스턴스만 강조 (다른 인스턴스는 반투명)
5. 신뢰도 슬라이더(`conf ≥`)로 표시할 인스턴스 임계값 조절

## 6. 로컬 이미지 분석

위성 검색 없이 **로컬 GeoTIFF 파일을 직접 업로드**하여 분석할 수 있습니다.

### 6.1 GeoTIFF 업로드 (Load Image)

1. 왼쪽 패널에서 **"Local Image"** 탭 클릭
2. **"Load Image"** 모드 선택
3. GeoTIFF 파일을 드롭존에 **드래그 앤 드롭** 또는 "browse" 클릭
4. 업로드 완료 후 자동으로:
   - 좌표계(CRS) 인식 및 지도에 배치
   - 밴드 개수, 이미지 크기 표시
5. **밴드 역할 매핑**: 각 밴드에 역할(NIR, RED, GREEN 등)을 지정하면 분광 분석 가능
6. R/G/B 슬롯에 밴드를 배치하여 시각화
7. **"Analyze →"** 클릭 → 분광 분석, 타겟 탐지, 세그멘테이션 모두 사용 가능

### 6.2 Band Registration (실험 결과 브라우저)

- **"Band Registration"** 모드 선택
- `experiment_results` 디렉토리에서 이미지/알고리즘 선택
- 시각화 전용 (분석 기능은 미지원)

## 7. 레이어 관리 및 비교

### 7.1 레이어 패널

분석 결과가 생성될 때마다 레이어로 등록됩니다. 왼쪽 패널 하단의 "Layers" 영역에서 관리:

- **눈 아이콘** — 레이어 표시/숨김 토글
- **드래그** — 레이어 순서 변경 (위에 있을수록 위에 표시)
- **투명도** — 레이어별 불투명도 조절

### 7.2 비교 모드 (Compare Layers)

두 개의 레이어를 나란히 비교하고 싶을 때 사용합니다.

1. **"Compare Layers"** 버튼 클릭
2. 화면이 좌/우 듀얼 맵으로 분할
3. 각 맵에 서로 다른 레이어 배치
4. 줌/팬이 동기화되어 같은 위치를 비교
5. 슬라이더를 좌우로 드래그하여 경계선 이동
6. **"Exit"** 버튼으로 단일 맵 모드로 복귀

## 8. 기타 기능

### 8.1 키보드 단축키

"Keyboard Shortcut Mode" 체크박스 활성화 후:

| 키 | 밴드 (Sentinel-2) |
|----|--------------------|
| 1 | B2 (Blue) |
| 2 | B3 (Green) |
| 3 | B4 (Red) |
| 4 | B5 (Red Edge 1) |
| 5 | B6 (Red Edge 2) |
| 6 | B7 (Red Edge 3) |
| 7 | B8 (NIR) |
| 8 | B8A (NIR Narrow) |
| 9 | B11 (SWIR1) |

→ 숫자키를 누르면 해당 밴드가 R/G/B 슬롯에 순차 배치됩니다.

### 8.2 AOI 파일 가져오기

| 형식 | 방법 |
|------|------|
| SHP (Shapefile) | zip으로 압축 후 드롭존에 드래그 앤 드롭 |
| KML | 직접 드롭존에 드래그 앤 드롭 |

### 8.3 데이터 다운로드

처리된 결과물을 GeoTIFF 형식으로 다운로드할 수 있습니다:

- 위성 원본 이미지 (전체 밴드)
- 구름 마스크
- 분광 지수 계산 결과
- 세그멘테이션 확률 맵
- 타겟 탐지 점수 맵
- SAM3 마스크 (point/text 모드 모두)
